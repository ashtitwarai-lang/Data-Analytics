# E-Commerce Conversion Rate Analysis

## Objective
Measure the e-commerce funnel and compare conversion performance by traffic source and device.

## Funnel
Visitors → Product Views → Add to Cart → Checkout → Purchase

## KPIs
- Conversion Rate
- Add-to-cart Rate
- Checkout Rate
- Revenue
- Average Order Value (AOV)

## Technology
Python, Pandas, Matplotlib.

## Run
```bash
pip install -r requirements.txt
python src/analysis.py
```

Outputs are saved in `outputs/`.
