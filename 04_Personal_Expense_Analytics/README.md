# Personal Expense Analytics

## Objective
Analyze personal spending patterns across categories and payment methods and compare needs versus wants.

## KPIs
- Total spending
- Average transaction value
- Category-wise spending
- Payment-method spending
- Needs vs wants

## Methodology
Data cleaning → KPI calculation → aggregation → visualization → insights.

## Technology
Python, Pandas, Matplotlib.

## Run
```bash
pip install -r requirements.txt
python src/analysis.py
```

The script creates CSV summaries and charts in `outputs/`.
