# Submission Guide

1. Install dependencies:
   `pip install -r requirements.txt`
2. Run:
   `python src/analysis.py`
3. Check the generated `outputs/` folder.
4. Submit the ZIP for the corresponding task.
5. Explain objective, dataset, methodology, KPIs, visualizations and observations.

The included datasets are sample/synthetic datasets for demonstration. If the internship portal provides its own dataset, replace the CSV while keeping the analysis logic compatible.
