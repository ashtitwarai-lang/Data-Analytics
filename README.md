# Social Media Reach Analysis

## Objective
Analyze social-media performance across platforms and content types using reach, impressions and engagement metrics.

## Dataset
`data/social_media_data.csv` contains 60 sample post-level records.

## KPIs
- Total Reach
- Impressions
- Engagements
- Engagement Rate = (Likes + Comments + Shares) / Reach × 100
- Reach Rate = Reach / Impressions × 100

## Technology
Python, Pandas, Matplotlib.

## Run
```bash
pip install -r requirements.txt
python src/analysis.py
```

Charts and summary CSV files are created in `outputs/`.
